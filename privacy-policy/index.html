Politique de confidentialité

Natacha est une application mobile autonome. Cette page explique quelles informations restent sur votre appareil et ce qui se passe lorsque vous choisissez de les partager.

Données de l’application

Les informations que vous saisissez — coordonnées des clients ou patients, rendez-vous, notes, prestations, devis, factures et paramètres — sont conservées dans une base de données chiffrée sur votre appareil. La clé de chiffrement est conservée dans le trousseau sécurisé d’iOS ou le stockage sécurisé d’Android.

Natacha ne nécessite pas de compte et n’exploite pas de serveur pour stocker ou synchroniser ces données. Le développeur ne peut pas consulter les informations conservées uniquement sur votre appareil.

Partages que vous déclenchez

Si vous choisissez d’envoyer un e-mail, un SMS ou une facture électronique, les informations nécessaires sont transmises au destinataire ou au service que vous sélectionnez. Les règles de confidentialité de ces services s’appliquent à leur traitement.

Service SuperPDP facultatif

Si vous connectez SuperPDP et soumettez une facture, les données de cette facture sont transmises à SuperPDP. Les jetons de connexion sont conservés dans le stockage sécurisé de votre appareil. Consultez la politique de confidentialité de SuperPDP pour en savoir plus sur son traitement des données.

Sauvegardes

Les sauvegardes sont chiffrées et protégées par un mot de passe. Vous choisissez où les enregistrer ou les partager. Natacha ne les téléverse pas automatiquement ; la confidentialité du lieu de stockage choisi dépend de son fournisseur.

Site web

Ce site statique n’intègre ni compte, ni cookie de suivi, ni outil d’analyse. Il est hébergé par GitHub Pages ; GitHub peut traiter des données techniques de connexion nécessaires à l’hébergement, selon ses propres règles de confidentialité.

Demandes d’assistance

Si vous contactez l’assistance via le dépôt GitHub, les informations que vous publiez seront traitées par GitHub et une demande publique peut être visible par tous. N’y incluez aucune donnée personnelle de client ou patient, facture, sauvegarde, mot de passe ou jeton de connexion.

Pour une question ou un problème, consultez la page d’assistance.

Privacy policy

Natacha is a standalone mobile app. Information you enter — client or patient details, appointments, notes, services, quotes, invoices, and settings — is stored in an encrypted database on your device. Its key is kept in iOS Keychain or Android secure storage. Natacha requires no account and operates no server to store or sync this app data.

When you choose to send an email, text message, or electronic invoice, the necessary information goes to the recipient or service you select. Submitting an invoice through optional SuperPDP sends invoice data to SuperPDP; connection tokens remain in secure device storage. Backups are encrypted and password-protected, and you choose where to save or share them. Natacha does not upload them automatically.

This static website has no account, tracking cookies, or analytics tool. It is hosted by GitHub Pages, which may process technical connection data under its own privacy rules. Support requests posted on GitHub may be public; do not include personal client or patient data, invoices, backups, passwords, or authentication tokens.

For questions, visit the support page.
